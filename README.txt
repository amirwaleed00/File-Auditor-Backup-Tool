Project: File Auditor & Backup Tool

Project Description:
A Bash program for scanning files, checking permissions,
reporting extensions, searching files, creating backups,
and restoring backup files.

Contribution:
All project functions were implemented individually.

How to Run:
./auditor.sh sample_data

Command Line Options:
./auditor.sh sample_data scan
./auditor.sh sample_data perms
./auditor.sh sample_data ext
./auditor.sh sample_data backup

Project Files:
auditor.sh - Main program.
lib.sh - Helper functions.
sample_data - Test directory.
